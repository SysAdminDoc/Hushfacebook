# Calibration cases for FingerprintCandidates.java: where each patch's target went between
# Facebook 577.0.0.50.72 and 580.0.0.51.74 (arm64-v8a, base.apk of each APKMirror bundle).
#
# Every case is a transition the patches already resolve on both builds. "old" is the method on 577
# and "new" the one on 580, as the patcher resolved them. Where a patch changes the method, the pair
# comes from DexDiff over verify-all-patches' output for each build (the method whose body gained
# the patch's code). Where a patch only reads the method, the pair comes from the fingerprint's own
# rule, applied to each build. test-fingerprint-candidates.ps1 holds the tool to ranking every
# "new" method in the top five, given only the "old" one.
#
# These names are one build's inventions, written down as calibration data. A patch never names one:
# ObfuscatedIdentityTest fails on that.
#
# One block per case: case <id>, then patch, role, old, new and one or more evidence lines.
